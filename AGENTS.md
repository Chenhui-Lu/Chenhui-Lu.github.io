# Public Landing Page Rules

This repository is public. It may contain only the minimal entrance page for Chenhui Lu's research progress portal.

- Never add research progress, project names, milestones, priorities, committee email addresses, or other private information.
- Keep the page minimal, academic, professional, responsive, and free of unnecessary animation.
- The primary action must link to the Cloudflare Access-protected dashboard.
- After any change, run `python3 scripts/validate.py`, review the diff, commit, push, and verify GitHub Pages deployment.
- Never commit credentials, tokens, keys, secrets, or OAuth configuration.
